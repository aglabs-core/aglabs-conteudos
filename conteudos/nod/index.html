Nod, o agente do n8n.
Passo a passo para instalar.

O Nod é um agente pessoal open source do n8n Labs que trabalha no seu computador, com navegador próprio, e pede o seu ok antes de agir. Aqui está como instalar, conectar o modelo de IA e passar a primeira tarefa. Sem cadastro.

Mac · Windows · Linux · 1 primeira tarefa · cuidados

1. Antes de instalar

  • Mac: macOS 14 ou mais novo, com chip Apple ou Intel.
  • Windows (versão de teste): Windows 11 de 64 bits. Para o Nod rodar no próprio computador, ele usa o WSL 2, com virtualização ligada e pelo menos 20 GB livres.
  • Linux (versão de teste): computador Intel ou AMD de 64 bits, Flatpak e o chaveiro do sistema (GNOME Keyring ou KWallet).
  • Modelo de IA: uma conta ChatGPT Plus ou Pro, uma chave de API (OpenAI, Anthropic, Gemini, OpenRouter e outras) ou um modelo rodando no seu computador.

2. Instalar no Mac

  1. Veja o seu chip em menu Apple → Sobre Este Mac.
  2. Baixe o instalador certo: chip Apple ou Intel.
  3. Abra o arquivo, arraste o Nod para Aplicativos e abra por lá. Na primeira vez, o Mac pergunta se quer abrir um app baixado da internet: clique em Abrir.
  4. Na tela de boas-vindas, escolha Get started.

3. Instalar no Windows

  1. Baixe o instalador para Windows e execute. Se o Windows avisar que o app é novo, confirme que quer instalar.
  2. Na tela de boas-vindas, escolha Get started.
  3. Se o Nod pedir o WSL, siga as instruções e aceite o pedido de administrador. Pode ser preciso reiniciar.

4. Instalar no Linux

Baixe da página de versões todos os arquivos nod-linux-x64.flatpak.partNN e o SHA256SUMS-linux-x64 para uma pasta vazia. Depois, nessa pasta:

terminal · Linux
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
cat nod-linux-x64.flatpak.part[0-9][0-9] > nod-linux-x64.flatpak && sha256sum --check SHA256SUMS-linux-x64 && flatpak install --user ./nod-linux-x64.flatpak
flatpak run io.n8n.Nod

Deixe o chaveiro do sistema desbloqueado durante a configuração: sem ele, o Nod não salva as chaves.

5. Conectar o modelo de IA

No app, abra Settings → Models → Add connection e escolha um caminho:

  • ChatGPT Plus ou Pro: escolha OpenAI, depois Sign in with ChatGPT, entre na sua conta e autorize. Em outros planos o login não funciona.
  • Chave de API: escolha o provedor, cole a chave e clique em Connect.
  • Modelo no seu computador: escolha OpenAI-compatible. O Nod já preenche o endereço do Ollama (http://localhost:11434/v1). Aí não há custo por pedido.

6. A primeira tarefa

Comece com uma tarefa pequena da sua lista. Um exemplo para colar:

pedido · cole no Nod
Compare estes três fornecedores e coloque o preço e o prazo de entrega numa tabela: [FORNECEDOR 1], [FORNECEDOR 2], [FORNECEDOR 3].

Antes de enviar, pagar, postar ou apagar algo que você não pediu, o Nod pergunta. As senhas e os cartões ficam guardados no seu computador, e o modelo não vê.

7. Cuidados

  • Custo: o Nod é grátis (licença Apache 2.0), mas o provedor de IA cobra o uso. Defina o limite mensal e acompanhe o custo de cada tarefa em Usage. Segundo o n8n, alguns testadores gastaram mais do que esperavam.
  • Notebook dormindo: se o computador dorme ou você fecha o app, nada roda. Para tarefas agendadas, deixe Open at login ligado ou use um servidor.
  • Versão de teste: cada instalação tem um dono só, e o Nod não faz ligações.
